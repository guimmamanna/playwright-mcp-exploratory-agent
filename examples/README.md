# Examples

## `reports/demo-session/`

Sample exploration output used by the dashboard and documentation:

- `session-memory.json` — session metadata
- `demo-todomvc-smoke-report.md` — session summary
- `bugs/` — individual finding markdown files

## Custom goals

See `src/config/sampleGoal.ts` for a minimal exploration goal. Copy and adapt for your application.

## Optional retail demo goal

`src/config/amazonGoal.ts` remains as a reference for complex retail sites. Use only on sites you are permitted to test.
